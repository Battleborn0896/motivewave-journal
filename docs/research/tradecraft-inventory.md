# TradeCraft trading journal (tradecraft.club), by the trader known as Fat Cat — Trade Craft Club LLC. Browser app at tradecraft.club/journal (public demo, app version v1.7.48 on 2026-10-10), with two desktop capture helpers: Tradecraft Beacon (Windows app for Rithmic R-Trader Pro) and a Sierra Chart custom study DLL.: feature inventory

Compiled from public pages on 2026-10-10 as a checklist for independent implementation. Behaviour is summarised in our own words; no vendor code, text or assets are used.

## Overview

TradeCraft is a tag-first futures day-trading journal. Its core idea: every trade gets a set of user-defined coloured tags (grouped into tag groups, optionally exclusive, optionally day-level), a 3-star rating (red = should not have taken, yellow = right trade with management flaws, green = perfect), a note, screenshots and a pointer into a YouTube session recording. Everything else is built on filtering those tags: a fully user-built dashboard (pages of split-pane widgets with a four-level filter hierarchy: global > page > widget > series), a live 'Calculate Stats' button that shows win rate / count / average / cumulative P&L for the tag combination currently selected (meant to be used BEFORE entering a trade), named 'Playbook Tag Combos' that light up when the selected tags match, a 'Book of Charts' gallery of screenshots and video clips filtered by tags, and 'CheckMate', a node-graph question/answer checklist that auto-applies tags and counts events.

The app has four left-nav sections: Dashboard, Journal (Daily Report Card + Daily Trades), Import, Settings (Tags, Accounts, Export, Checklists, General). A separate account dashboard at tradecraft.club/dashboard manages journals, the API key and downloads.

Trades arrive four ways: real-time from Sierra Chart (study DLL), real-time from Rithmic via the Beacon app watching a 1-second CSV export, file import from about 12 platforms, or manual 'dummy' trades. A distinctive workflow is pre-tagging: the trader adds an empty placeholder trade, selects tags while the setup forms, and the real trade later fills the placeholder and keeps the tags.

Method and limits of this inventory: sourced from the public marketing site, pricing page, all 38 knowledge-base articles, the KB screenshots, the public roadmap, the release notes, one blog announcement, and auto-caption transcripts of all 18 videos on the TradeCraft YouTube channel. No account was created and no logged-in screens were seen. The demo app is a client-rendered page whose script is obfuscated; I did not de-obfuscate it, so internal data shapes, API paths and full option lists are not confirmed (see unknowns). Release notes on the KB stop at 28 March 2025; later features (CheckMate, merging, R values, tag scores, radar and calendar widgets) are documented only by their own articles. Video-derived details come from auto-captions and are marked medium where wording was ambiguous.

## How trades reach the journal

WHAT RUNS WHERE
1) Server + web app: journals live on tradecraft.club. Each journal has its own fixed 'API URL' (labelled 'Remote URL' / 'Journal URL' in the helpers; generated at journal creation, cannot be changed, copied with a button in the account dashboard). Each account has exactly one secret API key (New Key / Show / Copy; generating a new one is the remedy if leaked; anyone holding it can submit trades). The Sierra study also asks for the account username. A completed roadmap item mentions bearer authentication for journal access, so the helpers most likely send the key as a bearer token over HTTPS to the journal URL (inference, not documented).

2) Sierra Chart path: a custom study DLL downloaded from the account dashboard 'Downloads' section, copied into the Sierra Chart Data folder (normally C:\SierraChart\Data), then added via F6 > Add Custom Study (it appears in the list as the Tradecraft/'Tradecraft Beacon' study). Three inputs: Username, API Key, Remote URL. It runs inside Sierra Chart on the trading PC and pushes trades to the journal over the network. It groups fills flat-to-flat into one trade with legs. Per the release note and the video it only reports trades for the symbol of the chart it is attached to, so it must be added to one chart per traded symbol (any one timeframe is enough); the KB article instead says any symbol syncs — conflicting statements. It also works in Sierra replay; in replay, as of Feb 2025, multi-leg trades arrived as separate trades. Trades show up 'relatively quickly' after the exit.

3) Rithmic path: no direct Rithmic API connection. The user configures R-Trader Pro's 'Recent Orders' window (Completed Orders section) with exactly these columns: Account, Status, Buy/Sell, Qty To Fill, Symbol, Avg Fill Price, Order Number, Update Time (EST), Qty Filled; then 'Export as csv periodically' with save-every = 1 second, 'append' unchecked and 'save daily' unchecked, to a chosen path. R-Trader therefore rewrites the whole file every second. Tradecraft Beacon is a native Windows app (installer from the dashboard; v1.0.2 in Feb 2025) with three inputs — API key, Journal URL, 'Select CSV File to Watch' — and a START SYNCING button; while running it shows the time of each sync. It reads the CSV, rebuilds positions flat-to-flat and sends trades to the journal. It works for any front-end that routes through the same Rithmic account as long as R-Trader Pro is running and exporting. In the demo a partial exit appears as a one-lot trade first and the same trade row grows (size 1 -> 2, extra leg) when the position goes flat. Rithmic gives no excursion data, so MAE and MFE arrive as 0.

4) Journal session 'Connect': with either real-time helper, the user must open the journal in a browser and press the Connect button (top right) at the start of each session. The connection times out after 1 hour and must be re-clicked; the vendor advises keeping the journal tab open and watching the connection. This is presumably a time-limited live channel that lets the open page receive pushed trades (mechanism not documented).

5) File import: Import tab > choose platform > the page shows that platform's export steps > Choose file > Upload > 'Success' with a link to the journal. Formats are CSV, XLSX or (MT5) HTML report. The journal page loads a CSV parser and a spreadsheet parser, so parsing may happen in the browser (inference).

6) Manual: the '+' button adds a blank 'dummy' trade that can be edited.

PLACEHOLDER MERGE (key behaviour): a pre-created dummy trade has no account, symbol, times or P&L. When a real-time trade arrives, or a file is imported, real trades are laid over the placeholders for that day in order and keep the placeholder's tags. For file import the vendor says the number of placeholders must equal the number of trades in the file. Row buttons insert a placeholder above or below an existing trade to fix ordering.

SYNC FREQUENCY: Rithmic — 1-second file cadence, 'virtually no delay'; Sierra — event driven on fills/flat. No end-of-day batch.

DUPLICATES: not documented anywhere public. For Beacon the watched file contains all of the session's completed orders on every rewrite, so it must de-duplicate itself; Order Number is a required column and is the likely identity key (inference). Nothing public says how re-importing the same file, or importing a file after a real-time session, is handled. Manual clean-up tools exist: delete trade, merge selected trades into one multi-leg trade, insert placeholder above/below.

PLAN GATING: real-time sync (both helpers) needs Basic or higher; file import is on every tier.

## Features

### capture

- **Four capture paths** (high): A journal can be fed by (1) the Sierra Chart real-time study, (2) Tradecraft Beacon for Rithmic R-Trader Pro, (3) file import from the Import tab, (4) manual placeholder trades. Sierra and Rithmic users may still use file import. Imported and synced trades appear under Journal > Daily Trades for their date. [source](https://support.tradecraft.club/kb/getting-started-step-by-step-guide/)
- **Tradecraft Beacon desktop app (Rithmic)** (high): Native Windows app installed from the account dashboard's Downloads section. Single small window with three controls on the left — 'API key', 'Journal URL', 'Select CSV File to Watch' — and a large START SYNCING button; the right pane lists sync activity with the time of each sync. Version 1.0.2 was current in Feb 2025; updates are done by re-downloading and re-installing. [source](https://support.tradecraft.club/kb/real-time-trade-sync-with-rithmic-r-trader-pro-tradecraft-beacon/)
- **R-Trader Pro one-second CSV export feeding Beacon** (high): User opens a Recent Orders window, sets the Completed Orders columns to exactly Account, Status, Buy/Sell, Qty To Fill, Symbol, Avg Fill Price, Order Number, Update Time (EST), Qty Filled, then chooses 'Export as csv periodically' with save every 1 second, 'append' off and 'save daily' off. R-Trader rewrites the file each second; Beacon watches it. Works when trading from another front-end on the same Rithmic account, provided R-Trader Pro is running. [source](https://www.youtube.com/watch?v=0if7Ai_Vh0Y)
- **Beacon trade assembly and scale-outs** (medium): Trades are built flat-to-flat. In the vendor demo nothing appears on entry; after a partial exit of a two-lot the trade appears with size 1 and one leg, and when the rest is closed the same row updates to size 2 with a second leg. The trader then tags and rates as usual. [source](https://www.youtube.com/watch?v=0if7Ai_Vh0Y)
- **Beacon limitation: no MAE/MFE** (high): Rithmic's order export carries no excursion data, so trades synced through Beacon show MAE = 0 and MFE = 0 until edited by hand. [source](https://support.tradecraft.club/kb/real-time-trade-sync-with-rithmic-r-trader-pro-tradecraft-beacon/)
- **Sierra Chart real-time study (DLL)** (high): A .dll downloaded from the dashboard Downloads section is copied to the Sierra Chart Data folder (C:\SierraChart\Data by default). In Sierra: select a chart or DOM, F6 (Analysis > Studies), Add Custom Study, pick the Tradecraft study, open its settings and fill three inputs: Username, API Key, Remote URL (the journal's URL). Browsers may flag the download as dangerous; the vendor says to allow it. Once active, closed trades post to the chosen journal. [source](https://support.tradecraft.club/kb/real-time-trade-sync-with-sierra-chart/)
- **Sierra study scope: per symbol, any timeframe** (medium): Release note and video: the study reports only trades on the symbol of the chart it sits on, so add it to one chart for each traded symbol; one timeframe per symbol is enough and trades taken from other timeframes of that symbol still arrive. The KB article instead says trades on any symbol sync. Treat per-symbol as the safer reading. [source](https://www.youtube.com/watch?v=bojrL93dyNo)
- **Sierra flat-to-flat grouping and replay** (medium): The study groups executions from flat to flat into one trade with legs. Sierra replay trades are also sent to the journal (useful for practice or backtest journaling). As of the Feb 2025 note, in replay multi-leg trades arrived as separate trades because grouping needed live data. [source](https://support.tradecraft.club/kb/whats-new-release-notes/)
- **Connect button with one-hour timeout** (high): For either real-time helper the user opens the journal and clicks Connect in the top-right corner at the start of each session. The link expires after 1 hour and must be clicked again; the vendor recommends keeping the journal tab open and monitoring the connection state. [source](https://support.tradecraft.club/kb/real-time-trade-sync-with-sierra-chart/)
- **API key and per-journal API URL** (high): Account dashboard (tradecraft.club/dashboard): Journals section has a copy button per journal for its API URL (created with the journal, immutable; a new URL needs a new journal). API Key section: one key per account; 'New Key' creates or replaces it, 'Show' reveals it, 'Copy' copies it. Warning that anyone with the key can send trades to the journal. A roadmap item renames the label 'api url' to 'remote url'. [source](https://support.tradecraft.club/kb/generating-api-key-and-viewing-api-url/)
- **Pre-tagging with placeholder ('dummy') trades** (high): Clicking '+' in the Trades header adds the next numbered trade with no account, symbol, time or P&L. The trader selects tags (and can run Calculate Stats) before entering. When the real trade arrives by real-time sync it fills that placeholder — timestamps, size, symbol, P&L appear — and the pre-selected tags stay. Without a placeholder, a new trade row is simply appended and tagged afterwards. [source](https://www.youtube.com/watch?v=0if7Ai_Vh0Y)
- **Insert placeholder above/below, delete trade** (high): Each trade row has three small icons: insert a dummy trade above, insert one below, and delete. Used to repair numbering when the trader added too many or too few placeholders during fast trading. [source](https://www.youtube.com/watch?v=xUmu7qe4WhY)
- **Real-time sync plan gating** (high): Rithmic and Sierra real-time sync are not on the Free tier; Basic, Premium and Lifetime include them. File import is on all tiers. [source](https://tradecraft.club/pricing)

### import and export

- **Import screen** (high): Left-nav document-with-arrow icon. A 'select platform' dropdown; choosing a platform shows its export instructions on the page; 'Choose file'; 'Upload'; a 'Success' message with a 'go to journal' link (which lands on the Daily Report Card). On error the user retries or contacts support. [source](https://support.tradecraft.club/kb/how-do-i-import-trades-from-my-platform/)
- **Supported import platforms and file types** (high): Atas (Statistics > history > Export statistics, .xlsx); Jigsaw Journalytix (My Trades, Show All, grey XLSX button); MetaTrader 4 (experimental; Account History > Save as Report; English UI required); MetaTrader 5 (experimental; History > Report > HTML, with Show Milliseconds on); NinjaTrader (Trade Performance, Display = Trades, values in Currency, CSV); Quantower (listed, instructions pending, importer bug open on roadmap); Rithmic R-Trader Pro (Order History/Recent Orders CSV); Sierra Chart (Trade Activity Log saved to file); TopstepX (Trades component CSV); Tradezella (CSV, brings tags and playbooks); TradingView (Export data > History CSV); Tradovate (Position History CSV); 'Custom' (developer use only). New platforms are added on request if the user supplies an export file. [source](https://support.tradecraft.club/kb/how-do-i-import-trades-from-my-platform/)
- **Platform-specific import inputs** (high): NinjaTrader: a 'Date format' input on the import form (MM/DD/YYYY or DD/MM/YYYY) must match the export. TopstepX: the export has no account number, so the user types the account into the form before uploading. [source](https://support.tradecraft.club/kb/how-do-i-import-trades-from-my-platform/)
- **Required columns: Rithmic file import** (high): Completed Orders columns for manual import: Account, Status, Remarks, Buy/Sell, Qty To Fill, Symbol, Qty Filled, Avg Fill Price, Limit price, Order Number, Create Time, Update Time, Commission. (A longer set than the nine columns Beacon needs.) [source](https://support.tradecraft.club/kb/how-do-i-import-trades-from-my-platform/)
- **Required columns: Sierra Chart file import** (high): Trade Activity Log columns (any order): Symbol, Trade Type, Entry DateTime, Exit DateTime, Entry Price, Exit Price, Trade Quantity, Max Open Quantity, Max Closed Quantity, Profit/Loss, Max Open Profit, Max Open Loss, Commission, Account. Profit/Loss format must be Currency Value and 'Use Commission' unchecked so P&L is gross. Max Open Profit / Max Open Loss are the evident source of MFE / MAE. [source](https://support.tradecraft.club/kb/how-do-i-import-trades-from-my-platform/)
- **Import overlays onto pre-tagged placeholders** (high): If the day already holds placeholder trades tagged live, importing the file fills them in chronological order with account, times, size, direction and P&L, keeping the tags. The vendor stresses that the number of placeholders must equal the number of trades in the file. [source](https://www.youtube.com/watch?v=YO28Js0g7_8)
- **Tradezella migration** (high): Importing a Tradezella CSV also creates tags and playbooks: Tradezella tag categories become TradeCraft tag groups. The user must export with exactly the tag-category columns plus a prescribed set of trade columns, selecting the trades via bulk actions > Export trades to CSV. [source](https://support.tradecraft.club/kb/how-do-i-import-trades-from-my-platform/)
- **CSV export of trades with tags** (high): Settings > Export: 'From' and 'To' date fields, a checkbox 'Ungroup trades with multiple legs' (one row per leg instead of per trade), and an 'Export csv' button. Output is a standard CSV of all trades in range including their tags; available even after downgrading. A PDF export with notes, screenshots and YouTube links was announced as a plan only. [source](https://support.tradecraft.club/kb/creating-managing-exporting-journal/)

### trade data

- **Daily Trades list** (medium): Left pane titled 'Trades' with columns #, Account, Entry Time (hh:mm:ss, newer builds with milliseconds), Size & Symbol shown as e.g. '12 · L ESM25' (size, L/S, contract), P&L, Duration (e.g. '1m, 36s'). An arrow marks the selected trade. Rows are tinted red / orange-yellow / green to match the trade's star rating; unrated rows are plain. Header tools: '+' add placeholder, merge, trash, gear (list settings), refresh; newer builds add a checkbox per row and a select-all box. The whole list can be collapsed. [source](https://support.tradecraft.club/kb/daily-trades-section/)
- **Trade Data panel (read view)** (high): For the selected trade: Account and Symbol, then a table with one row per leg plus a Total row and columns Size, Dir. (Long/Short), Avg. Entry Pr., Avg. Exit Pr., Entry T., Exit T., MAE (Curr), MFE (Curr), P&L (Curr). An Edit button switches to edit mode. [source](https://support.tradecraft.club/kb/daily-trades-section/)
- **Trade edit form** (high): Edit / Apply / Cancel buttons. Account dropdown with a 'New' link, Symbol with a 'New' link (both jump to Settings > Accounts), and 'Add leg'. Per leg: Size, Direction (Long/Short), Entry pr., Exit pr., Entry time with a separate ms box, Exit time with ms box, MAE (Curr), MFE (Curr), PS (Curr), PT (Curr), R Outcome dropdown (default 'Undefined'; e.g. 'PT reached first'), and two computed read-only lines: R (PnL/PS) and PnL (Curr). Help icons sit beside the excursion and R fields. [source](https://support.tradecraft.club/kb/calculating-trades-in-r-value/)
- **Manual / dummy trades** (high): Journal > Daily Trades > '+' creates a placeholder (defaults seen: size 1, Long, prices 0). Edit, fill in, Apply. Used for missed trades, hypothetical or backtest trades, or live pre-tagging. If saving reports 'invalid account name', create the account under Settings > Accounts > Add Account. Dummy trades are available on every tier. [source](https://support.tradecraft.club/kb/manually-adding-a-trade/)
- **Merging trades into multi-leg trades** (high): Tick the checkboxes of the rows to combine and click the merge icon (two arrows joining) in the Trades header. The result is one trade marked with an arrow whose Trade Data shows 'Leg 0', 'Leg 1', ... and a Total row. In the vendor example a 12-lot long and a 3-lot leg merge to Total size 15 with size-weighted average entry/exit prices. Meant for scale-ins/outs that imported as separate trades. [source](https://support.tradecraft.club/kb/merging-trades/)
- **Accounts and instrument settings** (high): Settings > Accounts: 'Add Account'; one card per account with a nickname, a gear, 'Delete Account' and 'Add Symbol'. Per-account symbol table: symbol (e.g. ESM25), point value (50), minimum price increment (0.25), commission, currency (USD), with edit and delete icons. Values are auto-filled for futures on import but may be wrong for less common contracts, so they are editable. A note states all commissions are round-turn. [source](https://support.tradecraft.club/kb/adjusting-tick-point-value-for-different-instruments/)
- **Display units for P&L and excursions** (high): Most widgets and the Book of Charts have a unit dropdown: Currency (total), Currency (per Contract), Points (total), Points (per Contract), Ticks (total), Ticks (per Contract), R (per Contract). P&L and MAE/MFE units can be chosen separately in the Trades Table and Book of Charts. [source](https://support.tradecraft.club/kb/radar-widget/)
- **R values: planned stop, planned target, R outcome** (medium): Each trade can carry a Planned Stop (PS), Planned Target (PT) and an R Outcome saying which would have been reached first if the trade had been left unmanaged. All three are typed by hand per trade; while R Outcome is 'Undefined' the trade is excluded from R results. The trade then shows 'R (PnL/PS)'. In the vendor screenshot PS 6952 with PnL 2400 displays R 0.35, i.e. PnL divided by the PS number as entered, so the exact unit handling should be verified. PS/PT are entered as price or ticks depending on journal configuration. [source](https://support.tradecraft.club/kb/calculating-trades-in-r-value/)
- **Commissions handling** (medium): Commission is stored per symbol per account (round-turn). Dashboard header has a 'Force commissions' checkbox and each series has an 'Include Commissions' option; the Trades Table has a Commissions column. Sierra file import expects gross P&L. [source](https://support.tradecraft.club/kb/adjusting-tick-point-value-for-different-instruments/)
- **Fractional sizes** (medium): Roadmap item marked done: trade size may be non-integer to support forex and crypto. [source](https://tradecraft.club/roadmap)
- **Journal timezone** (high): Settings > General lets the user choose the timezone used to display every date and time in the journal (added March 2025; later fixes for Europe/Paris and a Chicago issue listed on the roadmap). [source](https://support.tradecraft.club/kb/whats-new-release-notes/)

### tagging

- **Tags** (high): Settings > Tags > 'New Tag' (or the '+' on a group). Fields: Name (required, unique across the whole journal — duplicates are rejected), Description (optional), Color (picker), Score (any positive or negative number), Level checkboxes 'trade' and 'day', and 'Use with stopwatch timer'. Edit via the pencil that appears on hover. Renaming never detaches trades, so stats survive renames. [source](https://support.tradecraft.club/kb/creating-editing-and-managing-tags/)
- **Tag groups** (high): Settings > Tags > 'New Tag Group': name (unique), description, 'Exclusive' checkbox. A tag is unusable until it sits in a group, and an empty group is not shown in the journal. Tags are dragged into groups (target highlights) or created inside a group with its '+'. Edit with the pencil, delete with X — only when empty. Statistics belong to tags, not groups, so moving a tag between groups or deleting a group loses nothing. [source](https://support.tradecraft.club/kb/creating-editing-and-managing-tag-groups/)
- **Exclusive groups** (high): With Exclusive on, selecting a tag deselects any other tag of that group on the trade (radio behaviour). With it off, any number of tags in the group can be on. Example given: scalp vs hold should be exclusive; a 'yellow star' management group is left non-exclusive so two reasons can apply. [source](https://support.tradecraft.club/kb/exclusive-tag-group-setting/)
- **Trade-level vs day-level tags** (high): Per tag: 'trade' on shows it in Daily Trades; 'day' on shows it in the Daily Report Card, where one click applies it to every trade of that date (trades inherit it). Both on: it shows in both places, the report card toggles all trades, and a single trade can be overridden (e.g. sleep quality changes after a nap). Both off: hidden. Day-only groups appear in Daily Trades just as a line of inherited tags. [source](https://support.tradecraft.club/kb/day-vs-trade-tag-setting/)
- **Stopwatch / loop timer and timer-linked groups** (high): A countdown sits at the top of the Journal (default 05:00) with play, pause, stop and a 'Duration' box in whole minutes; 'Hide Stopwatch' removes it. Ticking 'Use with stopwatch timer' on any one trade-level tag attaches its whole group: the group shows a clock icon and flashes blue each cycle until a tag in it is picked. Intended for periodic check-ins (emotions, clarity); Fat Cat runs 3-minute loops and phrases such groups as questions. [source](https://support.tradecraft.club/kb/stopwatch-timer-tag/)
- **Reordering tags and groups** (high): In Settings > Tags each tag and group has a six-dot handle; drag to reorder. The order controls how groups and tags are laid out in the journal and the order tags appear in dashboard tag pickers. [source](https://support.tradecraft.club/kb/rearranging-groups-and-tags/)
- **Retiring vs deleting tags** (high): Dragging a tag into the 'un-grouped' area retires it: hidden from the journal and from dashboard filter pickers, but all attached trades are kept and it returns when dragged back into a group. Deleting (X on hover, with a confirmation) permanently removes the tag from every trade. [source](https://support.tradecraft.club/kb/creating-editing-and-managing-tags/)
- **Tag score** (high): Each tag has a numeric score (e.g. FOMO -1, PATIENT +1). A trade's Tag Score is the sum of its tags' scores. Usable as a metric in widgets (including Cumulative Tag Score and Average Tag Score, axis suffixed 'S'), as a Trades Table column, and as a filter with 'Bigger than' / 'Smaller than'. Per series, 'Score tags' > 'Select tags' switches between 'Use all tags' and a picked subset of tags/groups. [source](https://support.tradecraft.club/kb/assigning-a-score-to-tags/)
- **Tagging panel in Daily Trades** (high): 'Tags and Rating' section: rating stars, then buttons Copy Tags, Filters, Calculate Stats, Unhide All and a help icon, then playbook combo chips, then one card per tag group containing its tags as outlined pills. Clicking a pill toggles it; selected pills fill with the tag colour. Each card header has a checkbox (include in Calculate Stats), an eye icon (hide the group) and a clock icon if timer-linked. [source](https://support.tradecraft.club/kb/daily-trades-section/)
- **Copy tags between trades** (high): 'Copy Tags' clones the tag selection from one trade so it can be applied to another, for sessions where consecutive trades share most tags. Listed on every pricing tier. [source](https://support.tradecraft.club/kb/daily-trades-section/)
- **Hide / unhide tag groups** (medium): The eye icon collapses a group to save space; 'Unhide All' restores them. KB wording says groups can be hidden per trade. [source](https://support.tradecraft.club/kb/daily-trades-section/)
- **Calculate Stats (live tag-combination statistics)** (high): Tick the header checkbox of each group to constrain, select tags, click Calculate Stats. Result shows number of matching trades, win rate, average trade P&L and cumulative P&L. Rules: with nothing selected it covers all trades; a ticked group with tags selected requires exactly those tags; a ticked group with no tag selected matches any tag of that group; unticked groups are ignored. It does not auto-refresh — click again after any change. The adjacent 'Filters' button adds ordinary filters (e.g. only green-star, or exclude red-star) that persist across trades until removed. Premium-only ('real-time stats'). [source](https://support.tradecraft.club/kb/calculate-statistics/)
- **Tag limits by plan** (high): Free: 3 tags; Basic: 20 tags; Premium/Lifetime: unlimited. Tag groups and day-level tags exist on all tiers. [source](https://tradecraft.club/pricing)
- **Reference taxonomy: Fat Cat's own groups** (medium): Technicals: HTF Mean, Medium Mean, Micro Mean (each Favor / Mid / Against / None relative to a range midline on daily-30m, ~30s and 3-10s charts); Shimmy Entry (Favor/Mid/Against/None); Psych Price (On the point = within 3 ticks of a multiple of 5, Mid, Purgatory); Window (Open = first/last 10 minutes of the hour, Closed, Open/Closed, Closed/Open). Management: Trade Intention (Conservative/Aggressive), Yellow Star (Hold More, Better Entry, Held Too Long; non-exclusive), a misc group (Compression, Compression FAIL, Inventory clear, Stop run, Flip Hit, Mistake). Psychology on the loop timer: My read on PA (Clear/Inbetweener/Confused), calmness, contentment with P&L, patience (three levels each, phrased as questions). Day-level: Feeling Rushed, Nightly Hypnosis, Day type. [source](https://www.youtube.com/watch?v=iRu1PypO-5k)
- **Starter tag suggestions for new users** (medium): Vendor-suggested beginner set: HTF range and small range (fade / middle / breakout / none, exclusive), 'What's my intention?' (scalp / hold), Entry (perfect / too early / too late), Exit (same three), 'How am I feeling?' on the timer, My read on PA (clear / confused) on the timer, Random (mistake, wedge), Sleep Quality as a day+trade tag. Advice: give each tag in a group a distinct colour because series inherit tag colours, and add no new groups for a month. [source](https://www.youtube.com/watch?v=3GQB6C8CMeg)

### review

- **Three-star rating** (high): Three stars, single choice, per trade (and per day in the report card). Red = bad trade outside the system (impulsive, FOMO); yellow = valid trade with entry/exit management flaws; green = taken and managed as planned. Ratings tint the trade row, are a filter type at every dashboard level, a 'Color by' option, a sortable Trades Table column, and can label series (Rating 1/2/3). The default dashboard ships with an equity curve split by rating. [source](https://www.youtube.com/watch?v=u6N5BHa0nrc)
- **Screenshots per trade** (high): 'Screenshots' section under each trade: paste from clipboard, drag and drop, or click to browse; any common image type; then upload. Thumbnails expand on click. Limits: Free 0, Basic 2, Premium/Lifetime 5 per trade. Vendor recommends annotating with Flameshot and marking entry, exit, ideal entry, ideal exit and chart timeframe on the image. [source](https://support.tradecraft.club/kb/daily-trades-section/)

### sessions and recordings

### dashboard and statistics

- **Dashboard pages** (high): Tabs across the top; '+' adds a page; double-click a tab to rename; drag tabs to reorder; 'Clone Page' duplicates a page with its widgets and filters. New accounts start with a default page showing most widget types (raw equity curve, equity by rating, long/short and win/loss pies, day-of-week bars, stats table, trades table). Layouts persist. Page limits: Free 1, Basic 2, Premium unlimited. [source](https://www.youtube.com/watch?v=L4wVkZmhTkU)
- **Split-pane widget layout** (high): A blank pane offers a row of widget icons. Every widget header has: drag handle, trash, editable title, then maximize, split vertically, split horizontally, and copy. Splitting creates an empty pane beside or below; panes are resized by dragging dividers and widgets are moved by the handle. Trick shown: repeated vertical splits then deleting the extra give evenly aligned columns. Widgets per page: Free 4, Basic 10, Premium unlimited. [source](https://www.youtube.com/watch?v=L4wVkZmhTkU)
- **Four-level filter hierarchy** (high): 'Global filters' (beside the Dashboard title, all pages), 'Page filters', 'Widget filters' and per-series filters. A higher level overrides lower ones; when a filter type is set higher up, the same type shows a lock at lower levels. Each level opens a dialog with 'Select filter type' + 'Add Filter' and a list of active filters with trash icons. Filter types seen: Direction (long/short), Account, Symbol, Tag, P&L (bigger than / smaller than), MAE, MFE, Date (from/to), Rating, Tag Score. [source](https://www.youtube.com/watch?v=L4wVkZmhTkU)
- **Tag and rating filter semantics (include / exclude)** (high): In a Tag filter the full tag grid is shown; one click includes a tag (trade must carry it), a second click/double-click crosses it out (trade must not carry it). Multiple included tags are ANDed, so two tags of an exclusive group return nothing — to see 'either', exclude the others instead. Rating filters behave the same (to see yellow and red, cross out green). Unconstrained groups allow any tags. [source](https://www.youtube.com/watch?v=L4wVkZmhTkU)
- **Series** (high): Chart and stats widgets hold one or more series. A row under the header has '+' (add series), a clipboard (paste series), and per series: drag handle, colour swatch, name (double-click to rename), trash, gear, pencil (series filter) and the filter summary. Gear opens 'Series settings': Name, Color, P&L type (Real P&L / PT P&L), Score tags (Select tags), Show MAE, Show MFE, Include Commissions, Apply. A series filtered by one tag inherits that tag's colour. 'Hide serie settings' and 'Hide widget settings' checkboxes declutter the page. Series sets can be copied from one widget and pasted into another. [source](https://www.youtube.com/watch?v=L4wVkZmhTkU)
- **Equity line widget** (high): Dropdowns: metric (Cumulative P&L shown; tag-score metrics also available), x-axis (Trade number shown; date implied), unit; 'Markers' checkbox draws a dot per trade. Hover shows series name, trade count and running total; clicking a marker opens the trade. Multiple series overlay (e.g. long vs short, per tag, per rating). [source](https://support.tradecraft.club/kb/getting-started-step-by-step-guide/)
- **Pie chart widget** (high): One slice per series (e.g. longs vs shorts, wins vs losses, ratings, tags of a group). Built by adding series with filters; the default page includes several. [source](https://www.youtube.com/watch?v=L4wVkZmhTkU)
- **Histogram / bar widget** (high): One bar per series with a metric dropdown (e.g. Number of trades); used for win vs loss counts per tag, day-of-week performance and similar. A roadmap item notes the bars were too wide. [source](https://www.youtube.com/watch?v=L4wVkZmhTkU)
- **Statistics table widget** (high): One row per series, with a unit dropdown and a 'Columns' chooser. Columns seen: Name, Number of Trades, Cumulative P&L, Win %, Max Drawdown, Avg. Trade P&L, Avg. Trade MAE, Avg. Trade MFE, Avg. Drawdown, Biggest P&L, Max Consecutive Winners, Max Consecutive Losers. The vendor calls this the best widget for monthly review: one row per tag of every group. [source](https://support.tradecraft.club/kb/getting-started-step-by-step-guide/)
- **Trades table widget** (high): Paged list of matching trades with separate P&L and MAE/MFE unit dropdowns, 'Color by' (P&L, Rating, ...), and a 'Columns' chooser: Account, Symbol, Size, Side, Entry Price, Exit Price, Entry Date, Exit Date, P&L, P&L (PT), MAE, MFE, PS, PT, Commissions, Rating, Running P&L, Running P&L (PT), Duration, Tag Score. Click a header to sort either way; hovering a row shows the trade's tags; clicking a row opens the trade. It has widget filters but no series. [source](https://support.tradecraft.club/kb/calculating-trades-in-r-value/)
- **Radar chart widget** (high): Added from the widget picker; starts with three series. Header: metric dropdown (default Win %; e.g. Average Trade P&L), unit, Min and Max (centre and rim values; blank = auto-scale to the series), Color, and 'Flip' (for all-negative values such as scores). Negative min/max allowed. Each series is an axis. [source](https://support.tradecraft.club/kb/radar-widget/)
- **Calendar widget** (high): Month grid (Mon-Fri or with weekends) with previous/next month arrows and a 'Week' summary column (Week 1, Week 2, ...). Each day cell renders a mini chart of the widget's series for that day — chart type dropdown (Bar Chart shown) and metric dropdown (Number of trades shown) — or 'No Trades'. A 'Hide weekends' checkbox drops Saturday and Sunday. [source](https://support.tradecraft.club/kb/hide-weekends-in-calendar-widget/)
- **Custom script widget (experimental)** (high): A code editor with Source/Output toggle and a run button. User JavaScript reads the journal through globals tcTrades and tcTags, renders with a returnHtml(...) helper, and can load CDN libraries with an async importLibrary(url) (Chart.js given as the example). Labelled experimental; more data exposure is a planned item. [source](https://support.tradecraft.club/kb/whats-new-release-notes/)
- **Note widget** (high): A rich-text notepad pane (same toolbar as trade notes) for observations made while analysing, e.g. combos worth turning into a playbook. [source](https://www.youtube.com/watch?v=L4wVkZmhTkU)
- **Copy / paste widgets** (high): The copy icon puts a whole widget (type, series, filters) on a clipboard; an empty pane's picker includes a paste option, on the same or another page. Listed by the vendor as the ninth 'widget' (clone tool). [source](https://www.youtube.com/watch?v=L4wVkZmhTkU)
- **Managed vs unmanaged P&L comparison** (high): Setting a series' P&L type to 'PT P&L' plots what each trade would have made had it run to its planned target or stop (per its R Outcome) instead of the actual exit. Plotting a Real and a PT series together shows whether discretionary management adds or costs money; identical lines mean execution exactly as planned. [source](https://support.tradecraft.club/kb/calculating-trades-in-r-value/)
- **Edge-finding method built on the stats table** (medium): Vendor method: classify groups as technical / management / psychological; build one stats table per class with a row per tag (ordered highest timeframe first); insert heading rows by adding a series with an impossible filter (P&L below -1,000,000) and naming it; add rows for all trades, wins (P&L > 0) and losses (P&L < 0); then apply page-level tag filters one at a time and watch counts and win rates across all tables. Suggested minimums: 100-150 trades per tag group, about 10 trades in a combo before leaning on it. [source](https://www.youtube.com/watch?v=8-okPwuHBNY)

### checklists

- **CheckMate: checklist management** (high): Settings > Checklists: 'Add Checklist' creates 'Untitled Checklist' (double-click to rename). Per checklist: expand chevron, green play (run), up/down arrows (order), eye (hide from Daily Trades), trash (permanent), and edit (pencil). In Daily Trades a 'Checklists' section lists the visible ones with play, summary toggle, counter reset and edit only. Premium/Lifetime only. [source](https://support.tradecraft.club/kb/creating-checklists/)
- **Running a checklist** (high): Play shows the first question with its answers as buttons; clicking an answer advances along its connection until 'end of path'. Controls: restart everything, restart one sub-checklist, back one step, close a sub-checklist (X; play brings it back). One checklist canvas can hold several independent question trees that run side by side as sub-checklists; they can be dragged into a preferred order, which is remembered. [source](https://www.youtube.com/watch?v=sKCkwyD34IY)
- **Node editor canvas** (high): Edit opens a full-window canvas starting with one 'New Question' and one 'New Answer'. Toolbar: play, clear canvas, fit to screen; add Question, add Answer, add empty Passthrough, align horizontally, align vertically, restore default size, copy, paste, undo, redo. Double-click a node to edit its text. Shortcuts: Ctrl+C/V, Ctrl+Z, Ctrl+Shift+Z, wheel zoom, F fit, hold Space and drag to pan, drag to box-select, Delete. [source](https://support.tradecraft.club/kb/building-checklists-and-the-node-system/)
- **Node types and logging rules** (high): Question nodes (solid border) display a prompt and are never logged. Answer nodes (dashed border) are clickable choices and are always logged. Answers can be chained without questions (the answer text then serves as the logged prompt); two questions in a row insert a 'Continue' button. Passthrough nodes are empty routing points used to merge several arrows into one and keep loops tidy. [source](https://www.youtube.com/watch?v=XV9I9iC6T5s)
- **Connections** (high): Hovering a node shows orange connection dots; click one, then a dot on the target, to draw an arrow (click an arrow and press Delete to remove). With several nodes selected, clicking a dot on one side connects them all from that side. A node's '+' adds a pre-connected node of the alternate type. [source](https://support.tradecraft.club/kb/building-checklists-and-the-node-system/)
- **Answer nodes auto-tag the trade** (high): An answer's tag icon attaches one or more tags; clicking that answer while running the checklist on a trade applies those tags (respecting exclusive groups). Day-level tags can be attached too, so a pre-market checklist fills the Daily Report Card. Wrong tags can still be corrected by hand. [source](https://www.youtube.com/watch?v=sKCkwyD34IY)
- **Answer images and colours** (high): An answer can carry a thumbnail image (paste or drag) shown when the checklist runs, as a visual reference of the pattern. Node Properties sets border colours for questions and answers, which carry into the run view. [source](https://www.youtube.com/watch?v=sKCkwyD34IY)
- **Loops and global starting node** (high): Arrows may loop back so a checklist repeats through the session. A loop has no natural entry, so one node must be marked 'global starting node' (shows a green globe) or the checklist will not appear. [source](https://www.youtube.com/watch?v=XV9I9iC6T5s)
- **Event counter and answer summaries** (high): Each answer shows how many times it has been clicked (used to count tests of a level or range edge). A reset button zeroes all counters; a node option hides a given answer's counter; the count can be set by hand in the editor; Back also decrements. A summary toggle switches between a compact list (each distinct answer once, in first-click order) and the full click sequence. [source](https://www.youtube.com/watch?v=XV9I9iC6T5s)
- **Groups, display order, advanced options** (medium): Selected nodes can be wrapped in a named group (visual only; moves together). Sub-checklists and answers display oldest-node-first, so order is changed by copy-pasting a node to make it newer. Further options named but not explained publicly: prevent merging, clear summary, reset summaries, and per-arrow 'required', 'excluded', 'minimum loops to activate'. [source](https://www.youtube.com/watch?v=XV9I9iC6T5s)
- **Checklist JSON import/export and backups** (high): The editor's left panel exports a checklist as a .json file and imports one (for sharing or backup). 'New backup name' + plus saves a named server-side snapshot; each snapshot has restore (asks to confirm overwrite) and delete. [source](https://support.tradecraft.club/kb/building-checklists-and-the-node-system/)

## Per-trade fields

Trade number within the day (#), Date (session date), Account (with optional nickname; can be blurred), Symbol (contract, e.g. ESM25), Size (total; may be fractional), Direction / Side (Long or Short), Legs (Leg 0..n plus Total row; each leg has its own size, direction, prices and times), Avg. entry price, Avg. exit price, Entry time (date-time, with milliseconds), Exit time (date-time, with milliseconds), Duration, P&L (gross; shown in currency, points, ticks or R, total or per contract), Commission (round-turn, from per-symbol account setting), Running P&L (cumulative within the filtered set), MAE, MFE, PS — planned stop, PT — planned target, R Outcome (Undefined / PT reached first / stop reached first), R (PnL/PS), P&L (PT) — hypothetical P&L if left to planned target/stop, Running P&L (PT), Rating (1 red, 2 yellow, 3 green star), Tags (trade-level), Tags inherited from the day (day-level), Tag Score (sum of tag scores), Matched playbook combo name (derived from tags), Checklist answer log and counters, Screenshots (0/2/5 per trade by plan), Video position (derived from YouTube session start time and entry time), Journal note (rich text), Instrument metadata per symbol: point value, minimum price increment, currency, Day-level record: session rating, day tags, session note, YouTube sessions (video id, start time, end time)
